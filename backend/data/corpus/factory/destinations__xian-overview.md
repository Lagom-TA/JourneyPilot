# 西安目的地通用常识

西安市区以钟楼为中心展开，地铁线路覆盖钟楼、大雁塔、火车站与西安北站等主要节点，机场与市区之间可通过地铁或机场巴士接驳。首次到访可把住宿放在钟楼、鼓楼周边：这里去城墙、回民街和地铁站都方便；偏好安静的游客也可选择大雁塔、曲江一带。

兵马俑位于临潼区，距市区有一段车程，常与华清宫安排在同一天。两处都实行实名预约，建议通过官方渠道提前购票，并为往返交通和安检留出时间。西安城墙可以步行或骑行，永宁门是常用的登城点；城墙、钟楼、鼓楼之间距离不远，适合安排半天串联游览。

陕西历史博物馆通常需要提前预约，免费票在热门时段放票紧张，按官方公众号或小程序的公告操作；多数博物馆周一闭馆（法定节假日除外），出发前核对开放日与预约规则。景区和场馆的开放时间、预约入口会调整，行程以官方最新公告为准。
