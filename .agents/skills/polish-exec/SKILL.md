# polish-exec — 执行体验优化任务

以下项目路径均相对 JourneyPilot 仓库根目录。

1. 读 `docs/polish/README.md` 的“执行者须知”、适用的仓库说明和指定的任务文档全文。用户只给编号时，文档在 `docs/polish/tasks/<编号>.md`；没给时，查找状态为“待执行”或“返工”的任务，只有一份就执行，多份则问用户，没有则报告。
2. 按须知执行：状态改为“执行中” → 实现 → 运行第 6.2 节检查 → 写本轮执行记录 → 状态改为“待代码验收”。
3. 碰到停止条件立即停下，状态改为“受阻”，问题写进本轮记录，并告诉用户交回指挥。
4. 只改本任务文档的状态行与执行记录；不提交、不推送、不切分支。
5. 结束时向用户简要汇报改动、检查结果和遗留问题，提醒交给指挥做代码验收。
