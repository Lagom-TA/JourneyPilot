2026-11-05。采用作者选择的 **C「空间工作台」**。实现与代表路径验证完成，实现提交 `3bd2b42`。

## 当前行为

- 首页进入工作台时，新的不透明表面以短位移接管；进入和返回方向对应。平级页面沿导航顺序移动，不缩放整页正文，避免两套文字透明叠印。
- 研究台保留旅行身份与阶段导航，过程和确认门只交接主体。快照、焦点与画面使用相同的时长 token，任务的手动展开继续保留。
- 地图持续挂载，单日等内容在各自的不透明表面中切换。阅读版从右侧进入并沿原方向退出，支持进入过程中按 Esc 返回，保留地图和入口焦点。
- 手机面板连续跟随手柄拖动，按释放位置与速度吸附到 55%、92% 或关闭；目标没有改变时也会回弹。非模态面板不加遮罩、不锁住地图，手柄和关闭按钮具有独立的 44px 触控范围。
- 地点详情、图层、阅读版和手机面板使用统一 Esc 层级；内部已处理的按键不再关闭下层。阅读版退出后，原地点详情仍可保留。
- CSS 过渡显式使用缓动，纸屑动画与内容延迟使用 token；两类底部面板共用停靠判断。中英文 README 与前端说明同步当前行为。
