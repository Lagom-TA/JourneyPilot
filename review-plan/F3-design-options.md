## A · 旅行编辑页

**让方案和研究记录成为可阅读的正文。** 暖纸底色，极窄阶段栏，主文档占主要宽度。旅行身份合并为标题和一行元信息，去掉侧栏内逐项套框的摘要。

- **方案确认**：正文直接呈现完整研究方案，只保留一个主标题；补充要求与确认操作紧接正文。四阶段不再逐项解释。
- **调研中**：同一正文区域改为真实任务分组；每组显示状态和最新有效动态，来源与完整事件按需展开。动态不能只放在窄旁栏。
- **追问与终态**：问题或恢复操作接管正文首位，背景信息维持紧凑；只有实际可用的动作出现。
- **手机**：阶段栏收为一行，旅行信息一至两行，随后就是当前问题或方案；主要操作不排在整条阶段列表后。
- **优势**：确认方案的阅读与决策最自然，内容稍多时仍稳妥。
- **代价**：表达较接近成熟文档产品，作品辨识度主要依靠排版和状态衔接。

## B · 研究台面

**让一趟旅行的研究工作占据画面。** 顶部大目的地标题，下方是轻量阶段定位；主体用不等宽开放分区组织当前任务，以少量分隔线建立秩序，不把每个字段变成卡片。

- **方案确认**：左侧简短大标题，右侧承载完整方案与操作；长方案仍按原有段落阅读，不强行转成三张等高卡片。
- **调研中**：版式承载真实研究任务。目的地研究结束、交通与住宿并行时，突出正在进行的两组，已完成研究缩为紧凑记录；返研在原分组中明确轮次，不伪装成单向进度。
- **来源**：默认最新有效动态；点击任务区展开工具结果与资料，再次点击收起。桌面悬浮与键盘聚焦时出现轻量反馈和箭头，展开后及触屏上保留箭头。不额外设置“过程与来源”“点击展开”等说明性文案或加号。无真实事件时只显示当前状态，不生成循环播报、虚构数量或地点。
- **追问与终态**：需要用户作答或重试时，操作区域成为主位；已保留的研究仍可查阅，不用错误卡覆盖整张画布。
- **手机**：取消桌面分区，当前问题或操作优先；进行中的任务在前，已完成内容折叠。控制目的地、元信息、阶段定位的总高度。
- **优势**：能把并行调研本身做成展示画面，较适合代表作定位。
- **代价**：任务为空、只有一组、长地名或部分失败时仍需成立；不能为了构图补齐不存在的任务或图片。

## C · 聚焦画幅

**把当前动作放大，把过程档案收起。** 单栏大画幅，深绿工作面与粗体标题形成视觉重心。只显示一组旅行身份、当前阶段、真实并行任务概览和必要动作。

- **方案确认**：同一画幅中展示计划正文和一个确认动作，正文长度决定高度，不将内容裁成装饰性摘句。
- **调研中**：当前阶段作为大标题，交通、住宿等实际进行中的任务在下方简短并列；完整记录与来源通过展开进入。
- **追问与终态**：当前问题、研究重试或继续生成占据同一主位；异常不能藏进过程档案。
- **手机**：保持单栏关系，减少标题尺度；阶段定位与摘要不抢首屏。
- **优势**：最集中、最安静，首页转入和录屏具有较强连续性。
- **代价**：长时间运行时可见变化较少；如果把全部任务藏起，会损失并行研究和部分失败的辨识度。

## 共用的信息取舍

| 位置 | 默认保留 | 按需查看 / 触发后出现 |
|---|---|---|
| 旅行身份 | 目的地、日期 / 天数、出发地、人数，各表达一次 | 偏好、长目的地完整列表；待确认或暂定标在相应字段 |
| 阶段 | 四个短标签、当前 / 已完成 / 异常状态 | 选定阶段的完整记录、返回当前进展入口 |
| 调研 | 当前真实任务、最新有效动态、会影响下一步的异常 | 工具详情、来源预览、工作说明、里程碑和返研记录 |
| 确认 | 完整方案、补充入口、确认主动作 | 编辑区、未提交修改导致的禁用状态、提交失败与版本变化 |
| 终态 | 发生了什么，以及可用的下一步 | 已有记录与保留成果；不可继续时不出现继续按钮 |
| 输入 | 该状态允许的输入 | 仅已有交付后的调整显示排队反馈；追问和方案确认使用专用输入 |

不使用虚构百分比、剩余时间或占位资料；不把阶段背景说明在侧栏、标题和输入提示里重复。风景与纸品可用于一次过渡或小范围身份线索，运行期间不重复叠加首页装饰。
