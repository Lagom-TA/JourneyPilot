## 通用视觉检查（每张截图都要过）

- [ ] **观感**：第一眼的视觉焦点是否明确；配色、阴影、圆角、描边是否协调，整体是否有统一的气质；信息密度是否舒适，既不拥挤也不空洞；有没有让人记住的细节；是否像套用的模板。
- [ ] **文字**：基线与垂直居中、图标和文字是否对齐、标题衬线字体是否回退成其他字体、中英文和数字混排、长文本截断与换行（长地名、长标题、长按钮文字）。
- [ ] **布局**：网格对齐、间距节奏、同组卡片高度、留白分布（大屏两侧是否空荡、内容是否被拉得过宽）。
- [ ] **满屏适配**：高度是否刚好撑满、有无多余滚动条或底部空白、有无横向滚动、断点切换前后、刘海屏与底部安全区。
- [ ] **层级**：浮层之间的遮挡和叠放顺序、滚动容器是否嵌套出双滚动条。
- [ ] **状态**：加载占位和最终内容的尺寸是否一致（不跳动）、错误态有没有出路、禁用态是否可辨、焦点样式是否可见。
- [ ] **一致性**：同类组件（按钮、标签、卡片、弹层、空状态）跨页面的样式是否一致。

## 动效判断（看录屏或抽帧联系表）

- [ ] **节奏**：时长和缓动是否自然，有没有拖沓或突兀的地方。
- [ ] **连贯**：起止位置是否衔接，有没有闪烁、跳动或元素瞬移。
- [ ] **主次**：多个元素同时运动时，主次是否清楚。
- [ ] **质感**：有没有记忆点；与参考库中的同类动效相比如何。

## 结论写法

- 一个问题一行，写进阶段文件的“问题与修复”，用〔〕标出素材文件名。
- 借鉴了参考库中的某个条目时，附上链接。
- 纯审美取舍、没有对错之分的意见，写进[待决事项](decisions.md)，由作者决定。
- 一个场景看完后，把截图清单的“进度”改为 👁。
