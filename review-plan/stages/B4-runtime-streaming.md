## 审查项

- [x] **运行生命周期**：创建 → 取得租约 → 执行 → 状态收口；活跃连接有主要结束帧，断线以持久状态为准。
- [x] **控制与恢复**：停止、取消、中断、继续、服务重启后不自动继续花费、“正在停止”中间态与重复取消均已核对。
- [x] **预算与时限**：调用前预留并计入并发开销；预算和时限耗尽有可读提示；输入 token 与费用按估算值判断。
- [x] **事件清单**：生产者、消费者与未使用事件见 [B4 流式事件清单](../b4-events.md)。
- [x] **断线与多端**：用户确认断线即中断；按持久事件游标恢复状态与已保存内容，不补播实时增量。
- [x] **快速回答链路**：共用租约、控制、会话和流式收口；异常保存为完整错误轮次，重复提交可取回已完成回答。
- [x] **会话管理**：核对压缩、标题和历史分页；并发写入与超长轮次游标已修复。
- [x] **保证落地**：相关约定的 Owner 与测试位置已核对；本机 PostgreSQL 的临时表回滚验证覆盖关键事务边界。

## 问题与修复

- [x] B4-01 恢复扫描可能清掉已重新领取的租约或覆盖新状态 → 在同一事务重验租约并收口状态与控制命令。（提交 b8a073d）
- [x] B4-02 后台任务重领沿用进程级持有者，旧 worker 可能写下结论，失联重试也可能越过上限 → 每次领取生成独立持有者，校验有效期并收口耗尽的任务。（提交 b8a073d）
- [x] B4-03 失去租约的执行者仍可能写终态或提交交付，旧流清理可能停止新流 → 按租约令牌保护提交，并按句柄身份清理。（提交 b8a073d）
- [x] B4-04 模型调用前未预留预计费用，预算与时限耗尽也显示通用错误 → 预留并发费用并提供可执行提示。（提交 b8a073d）
- [x] B4-05 多个事件生产者可能同时占用同一个空位，正文容量判断也可能越界 → 唤醒后重新检查容量。（提交 b8a073d）
- [x] B4-06 同一会话并发写入会争用事件序号；超长单轮分页可能重复返回 → 对会话写入加行锁并使用整轮起始游标。（提交 b8a073d）
- [x] B4-07 中断和失败的对话记录未保留正确类型或完整错误轮次 → 保存中断类型与可读失败内容。（提交 b8a073d）
- [x] B4-08 快速回答重复请求只回放结束帧，遗漏已保存的正文 → 从会话记录恢复回答。（提交 b8a073d）
- [x] B4-09 连续追问遇到压缩快照会提前截断 → 跨过压缩快照并继续分页读取。（提交 b8a073d）
- [x] B4-10 读取画像期间断开可能遗留已领取租约 → 将读取纳入流的清理边界并提前启动心跳。（提交 b8a073d）
- [x] B4-11 事件清单缺失，部分不变量和 ADR 与现状不符 → 补齐清单并校正代码、测试和恢复语义。（提交 b8a073d）
- [x] B4-12 本机配置指向其他项目占用的 55433 端口 → 按用户确认固定现有 JourneyPilot 55434 数据库及持久卷供整个审查使用。（提交 b8a073d）
- [x] B4-13 中断错误帧在 API 投影时丢失运行状态 → 下发经校验的 `run_status`，让前端区分中断与普通失败。（提交 c76a8aa）
- [x] B4-14 费用数据不完整时仍显示看似准确的剩余额度，费用面板未说明上限可能失效 → 余额标记为未知，并在实时和最终费用面板提示。（提交 b8af718）
