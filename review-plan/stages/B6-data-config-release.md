## 问题与修复

- [x] B6-01 全部记忆删除与抽取任务并发时可能部分删除或写回 → 删除、取消任务、画像版本边界和审计同事务提交，拒绝删除前对话迟到入队。（提交 8d994d8）
- [x] B6-02 工作日志与运行终态锁顺序相反，等待期间过期的租约可能被使用 → 统一先锁运行行，在取得租约锁后及终态提交前检查实际时间，并在重领锁后起算租约。（提交 8d994d8、9d9a185）
- [x] B6-03 备份行数与转储可能来自不同快照，失败可能留下不完整目录 → 使用共享只读快照并清理本次失败的目录。（提交 8d994d8）
- [x] B6-04 缺少必要校验项的清单可能通过，恢复切换第二步失败可能留下原库名称不可用 → 强制校验必要文件并尝试恢复原库名，回退失败时报告保留库。（提交 8d994d8）
- [x] B6-05 数据库或 Redis 凭据含 URL 特殊字符时无法正确连接 → 对连接参数编码并使用 SQLAlchemy URL 对象。（提交 8d994d8）
- [x] B6-06 连接池打开失败和 MCP 探测退出时可能留下资源 → 在失败或退出路径关闭相应资源。（提交 8d994d8）
- [x] B6-07 MCP 包缺少版本号，前端及 MCP 依赖含可更新漏洞 → 统一为 `0.1.0`，更新兼容依赖并验证干净安装及离线握手；剩余 MCP 漏洞由 B5-13 处理。（提交 8d994d8、9c8f755）
- [x] B6-08 第三方 Open-Meteo MCP 启动时向第三方发送运行通知 → 默认禁用该 MCP 并在中英文 README 说明，内置天气适配器保留。（提交 8d994d8）
