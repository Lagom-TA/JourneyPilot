## 审查项

- [x] **动效一致性**：时长和缓动都来自 token（采集侧查代码）；同类动作使用同类动效；没有布局跳动；动画进行中点击不会引发状态错乱。
- [x] **键盘操作**：源码核对既有发送 / 提交按键；最上层 Esc、主题与目的地排序及相关输入路径经浏览器回归核对。
- [x] **鼠标与触屏**：悬停效果只在鼠标下生效；触屏点击目标的尺寸。
- [x] **性能体感**：本机离线入口、长正文及 40 条调研记录滚动已观察；地图按需组件与持久挂载路径经回归核对，真实网络加载与线上首屏未量测。
