## 审查项

- [x] **调研次序**：目的地先行，交通和住宿并行；失败或超时进入研究门，只能重试或取消，不能跳过失败直接交付；正常查无候选会进入组合。
- [x] **数据流转**：Packet 的候选、事实与来源经目录进入组合和投影；工具来源绑定本轮证据，事实与来源的语义对应仍依赖模型。
- [x] **补查与重做**：交通补查保留已有候选，受运行时预算、取消与时限约束；严重不可用的成果按角色重做，查无结果与工具失败分开返回。
- [x] **组合与落地**：1 天和 14 天日期须与确认结果一致；跨夜住宿与路线衔接有结构校验，营业时间的排程判断依赖模型。
- [x] **附属产出**：标题失败保留原行程；天气可生成替代建议；景点、餐饮、住宿和交通按单项展示价格，不合计。
- [x] **交付一致性**：Bundle 是交付来源；空白日期与待安排事项可进入报告及 PDF，前端展示待 F4 复核；投影失败不会提交正式交付。
- [x] **交付后更新**：天气刷新通过修订向量提交；PDF 渲染前后检查修订；对话修改生成新的 Run，原 Bundle 保留。
- [x] **修改相关模块**：当前没有 `itinerary/mutations/`、`delivery/workspace_mutations` 或工作台修改接口；交付后的调整经对话与规划链生成新 Run。
