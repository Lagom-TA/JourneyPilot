## 审查项

- [x] **工具授权**：每个角色的工具授权清单与实际注册的工具一致；按需暴露和完整加载的切换条件。
- [x] **工具执行**：超时、重试、失败时返回给模型的形状；“查无结果”和“技术失败”区分开。
- [x] **MCP 服务**：启动方式、环境变量白名单、没有密钥时的降级；四个自带服务各自的边界。
- [x] **模型路由**：主模型与快速模型的分工、任务到模型的映射、用量与费用的记账。
- [x] **外部数据源**：地点、路线、铁路、航班、天气、汇率各适配器的错误处理、限流和缓存。
- [x] **知识库**：上传 → 解析 → 分块 → 索引 → 检索 → 重排，以及体积、页数、压缩包展开量这几道上传边界。
- [x] **记忆与偏好**：自动提取、手动添加、去重、过期清理、全部删除；偏好和常用出发地的读写。全部删除与未完成任务的事务边界已提醒 B6。
- [x] **旅行风格**：增删改查、AI 生成指令、规划时如何注入。

## 问题与修复

- [x] B5-01 记忆抽取写入失败可能被吞掉，重领任务也可能重复产生业务副作用 → 让业务写入与已应用标记在租约保护下原子提交。（提交 0373c45）
- [x] B5-02 批量向量数量不足时会截断分块并替换原资料 → 在写库前校验向量数量与供应商返回顺序。（提交 0373c45）
- [x] B5-03 并发写入画像、偏好或常用出发地可能互相覆盖 → 只更新对应字段，并在抽取事务中串行聚合画像。（提交 0373c45）
- [x] B5-04 画像候选未引用有效事实时仍会入库 → 丢弃没有有效事实引用的画像。（提交 0373c45）
- [x] B5-05 记忆读取失败被当成空结果，界面和规划链无法识别缺失 → 将错误交给接口和约束装配入口处理。（提交 0373c45）
- [x] B5-06 汇率和金额可能接收非有限数字，产生无效报价 → 拒绝非有限值及溢出的换算结果。（提交 0373c45）
- [x] B5-07 MCP 同名工具可覆盖内置工具，按工具名授权也可能放行其他服务 → 保留原归属、按配置顺序注册并核验例外工具的服务来源。（提交 0373c45）
- [x] B5-08 并发添加同一句手动记忆可能重复入库 → 在事务内串行检查并写入。（提交 0373c45）
- [x] B5-09 目的地时区未知时天气窗口误用服务器日期 → 使用供应商返回的目的地时区判定预报与季节基线。（提交 0373c45）
- [x] B5-10 汇率 MCP 参数错误作为成功文本返回，可能被当作证据 → 用 MCP 错误返回无效参数。（提交 0373c45）
- [x] B5-11 缺少价格或完整用量时费用上限不再拦截 → 按 D-04 继续规划，费用余额标为未知并提示上限可能无法生效。（提交 b8af718）
- [x] B5-12 单条或分类删除可能与记忆总结交错，且总结无法感知用户手动管理 → 将手动管理记录、当前记忆和画像一起交给模型；并发变更时重试，明确新意愿可更新或删除事实，画像在后续总结时整理。（提交 6678aff）
