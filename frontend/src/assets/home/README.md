# 首页风景素材

四张原创生成图用于首页旅行灵感的全幅背景，文字与操作由网页渲染。

- 生成日期：2026-11-04。
- 服务与模型：[OpenRouter / GPT Image 2.5 Sunburst](https://openrouter.ai/openai/gpt-image-2.5-sunburst)。
- 参数：质量 `max`，比例 `16:9`，每个场景一张，无参考图。
- 原始尺寸：1536 × 864；生产图片使用 WebP，质量 88。
- 每张图片的完整提示词、生成参数和接口返回用量保存在同名 `.webp.json` 中。
- 风景用于表达旅行氛围，不表示具体地标的实拍记录。

默认只加载西北场景；切换时解码目标图像后再过渡。
